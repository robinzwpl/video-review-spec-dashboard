## 哪些命令在新机器上跑不通

- **03 抽帧 / 04 OCR** —— 需要源视频（113MB，未进仓库）与 OCR 环境，
  且本机 `turbojpeg`、`faster_whisper` 均未安装，第一次跑要先装依赖。
- **02 转写** —— 需要 faster-whisper 模型（约 483MB），缺失时该阶段跳过，
  不影响最终产物，只是少了章节定位。
- **06 解析及之后** —— 可以纯文本跑通，回归测试用的就是仓库内自带的
  `tests/fixtures/frames_ocr.json` 夹具，不需要视频。

## 口径说明

这批数据有几个容易踩的坑，看板顶部已统一标注：

- 色域分 sRGB / DCI-P3 / BT.2020 / BT.709 四种标准，量纲不同，不可直接比较
- 刷新率区分原生 4K 与倍频、以及 2K 模式下的高刷
- 峰值亮度需注明测试窗口口径（3% / 10% 窗口 vs 全屏）
- 背光分区存在单区 / 双区 / 多重分区算法差异
- 参考价为国补后价格，需符合地区补贴条件
